# JS AppnaClg

This folder is arranged in a simple learning order for beginner JavaScript practice.

## Folder Order

1. `01_Basics`
   Variables, data types, operators, strings, and simple object practice.

2. `02_Conditionals`
   `if`, `if-else`, odd-even, and grading examples.

3. `03_Loops`
   `for`, `while`, `do-while`, `for-of`, `for-in`, and basic number practice.

4. `04_Arrays`
   Array basics, loops on arrays, `slice`, and `splice`.

5. `05_Functions`
   Simple functions, return values, function arguments, and beginner array methods.

6. `06_DOM`
   DOM selectors and basic DOM manipulation.

7. `07_Events`
   Click and mouse events.

8. `08_Toggle_Button_Project`
   Small DOM and events practice project.

9. `09_Classes_And_Objects`
   Objects, prototype idea, and simple classes.

10. `10_Async_JavaScript`
    `setTimeout`, callbacks, promises, and async-await.

11. `11_API`
    Simple `fetch` example with button click.

## Notes

- The code is kept at a beginner level.
- Extra advanced code was avoided.
- Files are arranged in the order a student usually learns them.
