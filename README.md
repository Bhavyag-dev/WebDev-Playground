# WebDev Playground

A collection of hands-on web-development exercises, mini-projects, and course notes. This repository is a practical learning space for JavaScript, the DOM, APIs, Node.js, Express, authentication, MongoDB, and React.

## Contents

- `JS-AppnaClg/` — JavaScript fundamentals and browser exercises, including DOM manipulation, events, async JavaScript, API requests, and a toggle-button project.
- `WebDev-Cohort-3.0/` — Coursework and examples covering HTML/CSS, HTTP, Git, Bash, frontend DOM apps, backend development, JWT authentication, MongoDB, and React.

## Getting started

Most frontend examples are standalone HTML, CSS, and JavaScript files. Open an example's `index.html` in a browser, or use a local development server such as VS Code Live Server.

Some backend examples have their own `package.json`. From that example's directory, install its dependencies and start it with the command defined for that project:

```bash
npm install
npm start
```

If no `start` script is present, run the entry file directly, for example:

```bash
node index.js
```

## Notes

This is a learning repository, so examples are organized by topic and course week rather than as one deployable application. Environment-dependent backend projects include an `.env.example` file where required.
